# Student Performance Prediction

A Machine Learning project that analyzes student performance data and predicts students' grade classes using classification algorithms.

## Technologies

- Python
- Pandas and NumPy
- Matplotlib, Seaborn, and Plotly
- Scikit-learn
- Google Colab

## Models

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Project Workflow

1. Load and explore the student performance dataset.
2. Check for missing values and duplicate records.
3. Visualize features and examine outliers.
4. Prepare the features and target variable.
5. Split the data into training and testing sets.
6. Train and compare three classification models.
7. Evaluate performance using accuracy, classification reports, confusion matrices, and learning curves.
8. Analyze feature importance using Random Forest.

## Dataset

The notebook uses `Student_performance_data.csv`.

Upload the dataset to Google Colab when prompted, or place it in the same directory as the notebook when running locally.

## How to Run

1. Open `student_gpa_regression.ipynb` in Google Colab.
2. Upload `Student_performance_data.csv` when prompted.
3. Run the notebook cells in order.

## Project Purpose

This project demonstrates data preprocessing, exploratory data analysis, model training, evaluation, and comparison using Scikit-learn.
